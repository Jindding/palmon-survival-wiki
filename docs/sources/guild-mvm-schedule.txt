[1] 순환 로직 요약 (핵심)
────────────────────────────────────────────────────────────────

▣ 모험가 대회 (MvM)
  · 하루 6개 시간대에 5개 카테고리가 순환 배치됨.
  · 카테고리 순서 (고정): 펠몬강화 → 건물레벨업 → 아미고훈련 → 기술연구 → AP소모
  · 매일 시작 카테고리가 1칸씩 뒤로 밀림 → 5일 주기.
  · 요일 기준 고정이 아님. 즉 "이번 주 월요일"과 "다음 주 월요일"의
    시작 카테고리가 다름 (7 mod 5 = 2 이므로 매주 2칸씩 이동).

▣ 시간대 (KST 기준)
    slot 0 · 점심/오후  : 11:00 ~ 14:59
    slot 1 · 오후/저녁  : 15:00 ~ 18:59
    slot 2 · 저녁/밤    : 19:00 ~ 22:59
    slot 3 · 밤/새벽    : 23:00 ~ 02:59
    slot 4 · 새벽/아침  : 03:00 ~ 06:59
    slot 5 · 오전       : 07:00 ~ 10:59
  ※ 하루의 시작은 KST 11:00 (게임 서버 UTC−2 기준 자정)

▣ 앵커 (코드/계산 기준점)
    2026-08-10 (월) KST 11:00 → 시작 카테고리 = 아미고훈련 (index 2)
  이 시점을 0일로 두고 경과 일수로 다른 날짜를 계산.

[5] GvG ↔ MvM 겹치는 카테고리 (동시 점수 획득)
────────────────────────────────────────────────────────────────

  ※ 팰몬 경험치 소모 = MvM '펠몬강화' 카테고리와 동일.

  월(첩보 특훈)     ↔  AP소모 · 펠몬강화
                       (AP·첩보퀘스트·탈것식량 → AP소모)
                       (팰몬 경험치 500 소모 → 펠몬강화)
  화(캠프 건설)     ↔  건물레벨업
                       (건설가속·건설 전투력)
  수(기술 연구)     ↔  기술연구 · AP소모
                       (기술가속·기술 전투력 → 기술연구)
                       (첩보 퀘스트 1개 완료 → AP소모)
  목(팰몬 육성)     ↔  펠몬강화
                       (부화·팰몬 경험치·증표·스킬열매)
  금(전투 준비)     ↔  아미고훈련 · 건물레벨업 · 기술연구 · AP소모
                       (아미고훈련 Lv.1~9·훈련가속 → 아미고훈련)
                       (건설가속·건설 전투력 → 건물레벨업)
                       (기술가속·기술 전투력 → 기술연구)
                       (첩보퀘스트 → AP소모)
  토(적군 처치)     ↔  건물레벨업 · 기술연구 · 아미고훈련
                       (건설가속 → 건물레벨업)
                       (기술가속 → 기술연구)
                       (훈련가속 → 아미고훈련)
                       ※ 타인 아미고 처치는 MvM에 매칭 없음
  일               ↔  (GvG 없음)


────────────────────────────────────────────────────────────────
정리 메모
────────────────────────────────────────────────────────────────

1. MvM 카테고리는 요일 고정이 아닌 5일 순환. 매일 1칸씩, 매주 2칸씩 이동.
2. 앵커: 2026-08-10 (월) KST 11:00 → 아미고훈련 시작. 코드도 이 값으로 계산.
3. 하루의 시작은 KST 11:00. 그 이전 시각(자정~10:59)은 전날 스케줄에 속함.
4. GvG는 요일 기반 고정 미션이지만, MvM과 겹치는 시간대(황금 슬롯)는
   MvM이 순환하므로 매주 다른 시간에 발생함.
5. 이 문서 값이 바뀌면 src/lib/data/mvm.ts의 ANCHOR_UTC_MS · ANCHOR_START_INDEX
   또는 src/lib/data/gvg.ts의 미션 목록을 함께 갱신.
