[1] 핵심 관리 시설 (SR/SSR)
────────────────────────────────────────────────────────────────

▣ 캠프 (건설)
  추천 팰몬:
    SR  - 헤라클리프
    SSR - 맥시미토
  주 특성: 건축의별 → 건축시간
    S : 900초 감소
    A : 300초 감소
    B : 120초 감소
  보조: 몽상가 · 필로우킹 (수면 경험치)

▣ 연구대 (연구)
  추천 팰몬:
    SR  - 아우타이크
    SSR - 블릿볼트
  주 특성: 신동 → 연구시간
    S : 900초 감소
    A : 300초 감소
    B : 120초 감소
  보조: 몽상가 · 필로우킹

▣ 아미고 기지 (훈련)
  추천 팰몬:
    SR  - 킬로홉
    SSR - 브루즈베리
  주 특성: 코치 → 훈련속도
    S : 8% 가속
    A : 4% 가속
    B : 2% 가속
  보조: 몽상가 · 필로우킹 · 완속대사

▣ 병원 (치료)
  추천 팰몬:
    SR  - 플루팡
    SSR - 린다니어
  주 특성: 기적의손 → 의료시간
    S : 8% 가속
    A : 4% 가속
    B : 2% 가속
  보조: 몽상가 · 필로우킹

▣ 상점 (골드생산)
  추천 팰몬:
    SSR - 로토로터
  주 특성: 대식가 → 식사소모량
    S : 50% 감소
    A : 25% 감소
    B : 10% 감소
  보조:
    - 끝없는 의지 : 에너지소모량 50% 감소 (S)
    - 몽상가       : 수면시 추가 경험치 가루 15% 추가 (S)
    - 필로우킹     : 수면시 추가 경험치 가루 +3 초당 (S)

[2] 자원 생산 시설 (SR/SSR)
────────────────────────────────────────────────────────────────

▣ 테이블쏘 (목판생산)

  주 특성: 불피우기

[4] 작업 보조 특성 (Sub-Trait)
────────────────────────────────────────────────────────────────

  팰몬 특성 슬롯은 총 4개.
  주 작업 특성(예: 건축의별)을 3개 채우고 남는 1슬롯에 넣는 부특성.

  우선순위:
    1순위 → 몽상가
    2순위 → 필로우킹
    3순위 → 대식가 · 끝없는 의지 · 완속대사 (동순위)

  ────────────────────────────────────────────────────────────
  순위  특성          효과                    S         A         B
  ────────────────────────────────────────────────────────────
   1    몽상가        수면시 추가 경험치 가루 획득   15% 추가   10% 추가   5% 추가
   2    필로우킹      수면시 추가 경험치 가루        +3 초당    +2 초당    +1 초당
   3    대식가        식사소모량 감소         50% 감소   25% 감소   10% 감소
   3    끝없는 의지   에너지소모량 감소       50% 감소   25% 감소   10% 감소
   3    완속대사      배고픔게이지 감소       50% 감소   25% 감소   10% 감소

────────────────────────────────────────────────────────────────
정리 메모
────────────────────────────────────────────────────────────────

1. 시설별 SR/SSR 팰몬을 최소 하나는 확보해 배치하는 것이 성장 속도의 기본.
2. 같은 특성명이라도 S / A / B 등급에 따라 효과가 크게 차이. 등급 우선.
3. 팰몬 특성 슬롯은 4개 — 주 작업 특성 3개 + 보조 특성 1개 조합이 표준.
4. 작업 보조 특성 우선순위: 몽상가 > 필로우킹 > 대식가 · 끝없는 의지 · 완속대사.
5. 전투 팰몬은 앞라인(방어·체력)과 뒷라인(치명·공격) 특성을 분리해서 세팅.
