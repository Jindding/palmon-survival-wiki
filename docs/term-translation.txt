# 게임 용어 한국어 번역 대조표
#
# [왜 필요한가]
# 영어 자료(유튜브 자동요약 등)를 정리하면서 게임 내 한국어 명칭 대신
# 영어 표기나 음차가 그대로 들어간 곳이 있습니다.
# 한국 유저가 게임에서 보는 이름과 달라 헷갈리므로, 여기에 대조표를 만들어 두고
# 이 표대로 각 페이지의 표기를 한 번에 고칩니다.
#
# [작성 방법]
#   현재 표기 = 게임 내 한국어 명칭
#
#   - '=' 뒤에 게임에서 실제로 쓰는 한국어를 적어주세요.
#   - 그대로 두어야 하는 단어는 '= 그대로' 라고 적어주세요.
#   - 모르는 건 비워두시면 됩니다. 빈 줄은 건드리지 않습니다.
#   - 목록에 없는 단어를 발견하면 아무 곳에나 새 줄로 추가해도 됩니다.
#   - '#' 로 시작하는 줄은 메모입니다.
#
# [예시]
#   Miracle Temple = 미라클 사원
#   워 알터 = 전쟁 제단
#   Rubies = 그대로
#
# [참고]
# - 통상적인 외래어(버프 · 서버 · 이벤트 · 패스 등)는 목록에 넣지 않았습니다.
# - (제안) 표시는 사이트 다른 페이지에서 이미 쓰는 한국어를 미리 채워 둔 것입니다.
#   맞으면 그대로 두시고, 다르면 고쳐주세요.
# - 이 파일은 팰몬 허브에 페이지로 노출되지 않습니다. 반영 작업용입니다.
